## BAGIAN III: TARGET ARCHITECTURE vs IMPLEMENTATION STATUS — ENDPOINT MAPPING

> **Tujuan:** Tabel rekonsiliasi untuk developer/auditor agar setiap endpoint konseptual `/api/v1/...` yang muncul di SD/AD dapat dilacak ke **target capability Supabase** (PostgREST, GoTrue, Storage, Realtime, Edge Functions, pg_cron).
>
> **Dokumen ini adalah satu-satunya sumber status implementasi (as-built).** Status per mapping — `IMPLEMENTED` / `PARTIAL` / `DEPRECATED` / `OUT_OF_SCOPE` (serta `TARGET` untuk sisa roadmap aktif yang belum ada evidence) — tertulis pada BAGIAN III.B di bawah, bersama bukti kode (evidence path + symbol/RPC). Tabel `Target-Service Mapping` pada `plantuml_sequence_diagrams.md` hanya memetakan diagram ke target capability; status implementasi tidak duplikat di sana.
>
> **Implementation evidence fixed point:** `72049ef69997e1dceabbea03ad69424e5491b5d7`
> **Documentation correction base:** `c4665bb54269353186bd18e63990fb781ac216f7` (BR `batch-3a-corporate-intake`)
>
> Seluruh evidence di bawah **wajib diverifikasi terhadap commit `72049ef`**, bukan terhadap working-tree pengguna. Evidence path **harus exact** (tidak boleh wildcard migration `YYYYMMDD*.sql`); evidence symbol/RPC pun harus exact. Jika tidak ada evidence yang terverifikasi, kolom ditulis `No verified implementation evidence at fixed point` dan status fail-closed tidak boleh naik.
>
> **Sumber evidence yang sah:**
> - Migrasi database: `supabase/migrations/` saja (bukan `database/` legacy).
> - Konfigurasi Supabase: `supabase/config.toml`.
> - Adapter/seam frontend: `justifiqa-frontend/`.
> - Edge Functions: `supabase/functions/`.
>
> **Definisi status (fail-closed):**
> - `IMPLEMENTED` — **seluruh** evidence target lengkap dan diverifikasi terhadap commit tetap `72049ef`; tidak ada gap blocker.
> - `PARTIAL` — setidaknya satu evidence relevan (mis. RLS tabel tersedia, atau satu RPC tersedia) yang terverifikasi terhadap commit tetap; ada gap blocker yang ditulis.
> - `DEPRECATED` — pernah menjadi target, kini ditolak/diganti/dilebur (jelaskan blocker/gap); tidak boleh dilanjutkan sebagai target implementasi.
> - `OUT_OF_SCOPE` — diagram arsip/non-roadmap (bukan target Justifiqa aktif); dikeluarkan dari roadmap aktif, target implementasi, dan Definition of Done Justifiqa secara fail-closed. Diagram body tetap dipertahankan sebagai *historical / research reference*; pemeliharaan bukti/roadmap tidak dilakukan.
> - `TARGET` — diagram **aktif** (masih di roadmap Justifiqa/Phase 2) yang belum memiliki evidence apa pun yang terverifikasi terhadap commit tetap `72049ef`; status fail-closed untuk item roadmap aktif tanpa evidence.
>
> **Catatan fail-closed:**
> - `TARGET` = fail-closed untuk **active roadmap tanpa verified evidence**.
> - `OUT_OF_SCOPE` = fail-closed untuk **archived/non-roadmap**.
> - `PARTIAL` memerlukan setidaknya satu evidence relevan yang terverifikasi terhadap commit tetap `72049ef`.
> - `IMPLEMENTED` memerlukan seluruh evidence target lengkap dan terverifikasi.
> - Evidence yang tidak terverifikasi **dilarang** menaikkan status menjadi `PARTIAL` atau `IMPLEMENTED`. Jika bukti tidak dapat diverifikasi terhadap commit tetap `72049ef`, kolom Evidence ditulis `No verified implementation evidence at fixed point` dan status fail-closed yang sesuai (`TARGET` untuk active no-evidence, `OUT_OF_SCOPE` untuk archived) dipakai.
